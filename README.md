# Computer Service — учебный PHP-сайт

## Что нужно
- PHP 8.0 или новее
- Для MySQL: MySQL или MariaDB (сайт также отображается без базы данных)
- Apache/XAMPP либо встроенный PHP-сервер

## Запуск через XAMPP
1. Распакуйте папку `computer-service` в `C:\xampp\htdocs\`.
2. Запустите Apache в XAMPP.
3. Откройте `http://localhost/computer-service/`.

## Запуск без XAMPP
1. Установите PHP и перейдите в папку проекта в терминале.
2. Выполните `php -S localhost:8000`.
3. Откройте `http://localhost:8000`.

## MySQL (необязательно для первого запуска)
1. Откройте phpMyAdmin или клиент MySQL.
2. Импортируйте файл `database/schema.sql`.
3. Если у MySQL не стандартный пользователь или пароль, измените `$dbHost`, `$dbName`, `$dbUser`, `$dbPass` в `config/database.php`.

Сейчас страницы и демонстрационные цены берутся из `languages/lv.php`, `languages/en.php` и `languages/ru.php`. SQL-файл создаёт таблицы и добавляет примерные цены в базу. Чтобы редактировать сайт через базу данных, понадобится отдельный следующий шаг по подключению запросов к таблицам.

## Где что находится
- `index.php` — выбирает страницу и язык.
- `pages/` — содержимое пяти страниц.
- `includes/` — общие шапка, меню и подвал.
- `languages/` — переводы LV / EN / RU.
- `config/database.php` — подключение к MySQL.
- `assets/css/style.css` — весь дизайн и адаптивность.
- `assets/js/script.js` — мобильное меню.
- `database/schema.sql` — SQL-таблицы и демонстрационные данные.

## Перед сдачей
- Замените `TECH SERVICE` на выбранное название компании.
- Добавьте реальные согласованные телефон, email, адрес, часы работы и ссылку на точку на карте.
- Проверьте все три языка и мобильное меню.
- Цены здесь демонстрационные — отредактируйте их по требованиям преподавателя.
